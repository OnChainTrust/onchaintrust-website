One compliance layer. Any identity backend. Every tokenized asset.

OnChainTrust is a compliance middleware layer with a pluggable identity architecture. It verifies credentials from any supported backend — vLEI, EAS, ONCHAINID — and delivers a single, standardized compliance answer to any token contract.

What we are

  • An identity-agnostic verification layer. Any supported credential feeds into a single compliance interface for ERC-3643 and ERC-7943 token contracts.
  • A policy engine that enforces per-token, per-jurisdiction compliance rules before transactions execute.

What we are not

  • Not an identity provider. We don’t issue credentials. Identity providers do that. We verify and translate.
  • Not a closed enterprise platform. OnChainTrust is open and modular — any identity provider can plug in, any token issuer can integrate.

How It Works

1

Credential Verification

Institution presents an identity credential. OnChainTrust verifies it against the issuing infrastructure and extracts entity identity, representative identity, and organizational role.

2

Policy Evaluation

Policy engine checks jurisdiction rules, asset class requirements, and entity eligibility. Configurable per token issuer.

3

On-Chain Response

Token contract receives a simple true/false via canTransfer(). Works with ERC-3643 and ERC-7943.

One integration point. No changes needed to token contracts.

Compliance Circuit Breaker

Without OnChainTrust

Regulatory exposure for every token issuer

With OnChainTrust

  • All dependent token contracts updated instantly
  • Transfers blocked before the next transaction

Continuous compliance, not point-in-time

Built on the Strongest Credential

OnChainTrust supports any identity backend — but we lead with vLEI, the only globally mandated, cryptographically verifiable standard for institutional identity in financial transactions.

Already Mandated

Required by G20 regulation. Used in MiFID II, EMIR, Dodd-Frank. Compliance teams already know it.

Cryptographically Verifiable

vLEI binds entity identity (LEI) + individual identity + organizational role into one credential. No self-declaration, no trust-me forms.

Globally Recognized

2.9M+ LEIs issued. Governed by GLEIF. Mandated by regulators in 45+ jurisdictions.
