Why DApps Need a Second Line of Defense

Frontend hacks, DNS hijacks, and phishing domains are increasing. When a DApp’s interface is compromised, users sign transactions to malicious contracts without knowing. By the time the team reacts, funds are gone.

Frontend Hacks

Attackers compromise a DApp’s website and redirect transactions to malicious contracts. Users see the familiar interface but interact with the wrong addresses.

DNS Hijacking

Domain DNS records get changed to point to a phishing clone. The URL looks right, the SSL certificate is valid, but the site is fake.

Unverified Contracts

Users interact with smart contracts they can’t verify. One wrong approval and an entire wallet can be drained.

How OnChainTrust Protects Users

Domain Verification

DApp owners register and verify their domain with OnChainTrust. We confirm domain ownership and link it to a verified entity identity. Users and wallets can check whether a domain is legitimate before any transaction.

Verified domains are stored on-chain and queryable by any wallet or browser extension.

Address Whitelists

DApp owners declare the specific smart contract addresses that users should interact with from their domain. Any transaction to an address not on the whitelist is flagged or blocked at the wallet or browser extension level.

Example: Uniswap registers uniswap.org → only Uniswap router and pool contracts are whitelisted. A compromised frontend trying to route funds to an attacker’s contract is blocked.

Kill Switch

When a DApp owner detects a compromise — a frontend hack, a DNS hijack, a reported vulnerability — they activate the Kill Switch. It immediately discourages all user interaction with the domain until the issue is resolved.

Kill Switch is controlled exclusively by the verified domain owner. Activation is instant. Wallets and extensions with OnChainTrust integration block transactions to the affected domain.

How It Works

1

DApp Owner Registers

Register your domain and verify ownership on OnChainTrust. Declare the smart contract addresses your users should interact with.

2

Users Install Extension

Users install the OnChainTrust browser extension or use a wallet with OnChainTrust integration. No setup needed — protection is automatic.

3

Real-Time Protection

Every time a user initiates a transaction from a verified domain, OnChainTrust checks the target address against the whitelist. Unrecognized addresses are flagged.

4

Incident Response

If something goes wrong, the DApp owner activates the Kill Switch. All users are immediately warned. Transactions are blocked until the all-clear.
